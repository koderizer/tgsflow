# TGS Plan Phase

Research must be approved before starting this phase.

## Steps

### 1. Author plan.md
Use the template at `tgs/agentops/tgs/plan.md`. Link to research.md — don't re-explain the problem.

### 2. Right-Size
| Complexity | Target |
|-----------|--------|
| Bug fix | ~80 lines |
| Single-module | ~200 lines |
| Multi-module | ~300 lines |

### 3. Commit, Push, and Ask for Review
Tell the human: "Please review `plan.md` in `tgs/<dir>/`. Reply: APPROVE plan | REQUEST CHANGES: <notes>."
